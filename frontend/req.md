We need to build a modern React application with a clean, scalable, and production-ready architecture.

### Requirements

* Use **React** with a well-organized and maintainable folder structure.
* Use **Redux Toolkit** for global state management.
* Follow a clear architectural pattern, separating the application into layers such as:

  * **UI (Components/Pages)**
  * **Services** (Business logic)
  * **Repositories** (API/Data access)
  * **Redux** (State management)
  * **Hooks**
  * **Utilities**
  * **Constants**
  * **Types**
* The project structure should be designed for long-term maintainability, making it easy to scale, test, and modify without creating tightly coupled code.
* Follow industry best practices, including reusable components, separation of concerns, and feature-based organization where appropriate.

### UI & UX

* The UI should have a **premium Apple-inspired aesthetic**:

  * Clean and minimal design
  * Elegant typography
  * Plenty of whitespace
  * Smooth animations and transitions
  * Glassmorphism where appropriate
  * Subtle shadows and modern gradients
* Implement **Lenis** for smooth scrolling throughout the application.
* Ensure the application is fully responsive and optimized for desktop, tablet, and mobile devices.
* Prioritize accessibility, performance, and a polished user experience.

### Code Quality

* Use **TypeScript**.
* Follow consistent coding standards and naming conventions.
* Keep components small, reusable, and single-purpose.
* Avoid code duplication.
* Ensure the architecture supports easy addition of new features without major refactoring.
* Structure the project so that API integrations, UI components, business logic, and state management remain independent and easy to maintain.

The goal is to create a codebase that is clean, scalable, modular, and maintainable while delivering a premium user experience comparable to high-quality modern websites.
